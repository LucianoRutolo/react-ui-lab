# React UI Lab

A personal project created to practice and improve my frontend development skills by building reusable React components.

The main goal of **React UI Lab** is to experiment with different UI patterns, interactions, and component designs while keeping the code reusable, maintainable, and easy to understand.

The project also serves as a collection of examples that can be shared and reused in other projects.

## ✨ Goals

* Practice and improve React and frontend development skills.
* Build reusable and configurable UI components.
* Experiment with different UI patterns and interactions.
* Improve TypeScript knowledge and component typing.
* Explore responsive and accessible UI design.
* Keep components simple, reusable, and easy to integrate.
* Share the source code and implementation details.

## 🛠️ Technologies

* React
* TypeScript
* Vite
* Tailwind CSS
* Lucide React

## 📦 Components

The project will gradually include different reusable components, such as:

* Data Table
* Pagination
* Buttons
* Inputs
* Modals
* Dropdowns
* Cards
* Tabs
* Tooltips
* Loaders
* And more...

Each component is designed as an independent and reusable piece of UI whenever possible.

## 🚀 Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project:

```bash
cd react-ui-lab
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 📁 Project Structure

```text
src/
├── components/
│   ├── DataTable/
│   ├── Button/
│   ├── Modal/
│   └── ...
├── App.tsx
├── main.tsx
└── index.css
```

The structure may evolve as the project grows and new components are added.

## 🎯 Philosophy

This project is primarily a learning and experimentation space.

The goal is not to create a production-ready UI library, but rather to understand how reusable components can be designed, typed, composed, and adapted to different use cases.

Some components may evolve over time as I learn better approaches or discover new patterns.

## 📖 Sharing

The source code of the components is available so that other developers can explore the implementations, learn from them, or use them as inspiration for their own projects.
